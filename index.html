HOW TO GET DHAN CREDENTIALS
1
Open Dhan API portal
Go to api.dhan.co and log in with your Dhan trading account credentials.
2
Create an app
Click "Create App" → App Name: Smart Money Dashboard → Redirect URL: your GitHub Pages URL
3
Copy Client ID and Access Token
After creating app, copy your Client ID and generate an Access Token. Paste both above.
4
Daily token refresh
Access Token expires every 24 hours. Each morning go to api.dhan.co → regenerate token → paste here → Save.
